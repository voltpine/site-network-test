# Site Network — тестове завдання

Це спрощена копія нашої мережі контентних сайтів: один Laravel-код обслуговує кілька
доменів, кожен зі своїм набором статей. Сайти китайськомовні, контент справжній.

AI-інструменти (Claude Code, Cursor тощо) дозволені й вітаються.

## Запуск

Потрібні PHP 8.3 і Composer. Node не потрібен.

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Сайти відрізняються за хостом. Імена `*.localhost` браузер і curl резолвлять
самі, нічого в `/etc/hosts` дописувати не треба:

- http://androidpixels.localhost:8000/
- http://gplaytips.localhost:8000/

Тести: `php artisan test`.

## Як це влаштовано

- `app/Http/Middleware/ResolveSite.php` знаходить сайт за хостом і кладе його в запит.
- `routes/web.php` — головна, сторінка рубрики, стаття, `sitemap.xml`, `robots.txt`.
- `templates/<name>/` — шаблон сайту: `site.json` (назва, рубрики, тема) і `articles/*.json`.
- `database/seeders/DatabaseSeeder.php` розгортає два сайти з цих шаблонів.
- Стилі лежать у `public/css/site.css`, ілюстрації в `public/img/`.

## Завдання

### 1. Індексація і швидкість

SEO-команда скаржиться: сайти мережі погано індексуються в Google і Bing, а на
мобільних сторінки «стрибають» під час завантаження. Знайди причини в коді та
виправ їх. Скільки їх — не кажемо. Дивись на сайт очима пошукового бота: що він
отримує у відповідь, які заголовки, куди ведуть посилання.

### 2. Команда запуску сайту

Зараз новий сайт з'являється лише через сидер, який скопійовано двічі. Зроби
консольну команду:

```bash
php artisan site:create {domain} {template}
```

Вона має створити сайт із шаблону в `templates/{template}/` разом із рубриками
й статтями, щоб одразу працювали головна, сторінки, `sitemap.xml` і `robots.txt`.
Повторний запуск для того самого домену не має дублювати дані. Сидер після цього
має використовувати ту саму логіку, а не свою копію.
